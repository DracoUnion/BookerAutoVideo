# BookerAutoVideo 代码结构

音视频自动处理工具链（文本→视频合成、ASR 语音识别、关键帧提取、图像分类、视频切分）。

命令行入口来自 `pyproject.toml` `[project.scripts]`：`BookerAutoVideo`、`bav`、`auto-video`，均指向 `BookerAutoVideo.__main__:main`。

代码全部位于 `BookerAutoVideo/` 包内，按职责分为 6 类模块：

## 1. 入口与命令注册

+ `__main__.py` — 唯一入口。构建顶层 `argparse` 解析器（含 LLM 公共参数：`-m/--model`、`-k/--key`、`-H/--host`、`-vm/--vmodel`、`-im/--tti-model`、重试/温度/超时/流式等），遍历各模块调用其 `reg_subparser(subparsers)` 注册子命令，最后 `args.func(args)` 派发。当前注册 `gen`、`note`、`ext-ppt`、`metric`、`clip-test`、`split`、`remotion`、`sv2api`、`comic-drama`、`md2note` 十个子命令。
+ `__init__.py` — 包元信息（`__version__`，作者 wizardforcel，SATA 协议）。

## 2. 视频与音频处理

+ `autovideo.py` — `gen` 命令：文本转视频（edge-tts TTS + DALL-E 文生图 + ffmpeg 音视频合成 + 字幕）。
+ `video2note.py` — `note` 命令：音频/视频转笔记（SenseVoice ASR + 关键帧截图 + Markdown 排版 + LLM 生成笔记）。
+ `ext_ppt.py` — `ext-ppt` 命令：视频关键帧提取（抽帧、色度/HOG 过滤、帧间差去重、PPT 模型与 OCR 语义过滤、图像优化）。
+ `split.py` — `split` 命令：基于 ffmpeg 的视频切分。
+ `sencevoice.py` — SenseVoice/FunASR ASR（VAD 分段 + 多语言语音转文字，结果缓存到 `data/`）。
+ `ffmpeg.py` — ffmpeg 命令行封装（探信息、格式转换、拼接、截帧等）。
+ `autovideo_config.py` — 视频生成配置（画布、帧率、时长、字体等）。

## 3. 图像与多模态

+ `imgsim.py` — `metric` 命令：图片相似度指标（colorfulness/HOG/sharpness/哈希等，单图与目录对比）。
+ `clip.py` — `clip-test` 命令：中文 CLIP 图像分类。

## 4. LLM 工作流（编排器 + 智能体模式）

+ `remotion.py` + `remotion_agent.py` + `remotion_models.py` (+ `remotion_pmt.py`) — `remotion` 命令：用大模型编写 Remotion 代码并渲染视频（分场景大纲 → 工程文件生成 → 校验 → 渲染，逐文件 YAML 缓存）。
+ `comic_drama.py` + `comic_drama_agent.py` + `comic_drama_models.py` (+ `comic_drama_pmt.py`) — `comic-drama` 命令：漫剧 Agent（ScriptBreaker 剧本拆解 → ImageGen 文生图 → KeyframeGen 关键帧 → VideoGen 成片合成，逐步缓存）。

## 5. 服务

+ `sv2api.py` — `sv2api` 命令：Flask 服务，将 SenseVoice 封装为 OpenAI 兼容 `/v1/audio/transcriptions` 转录 API。

## 6. 共享基础设施

+ `openai.py` — LLM 客户端层（与 BookerAutoTool 共享实现，`OpenAIClient` 等）。
+ `util.py` — 通用工具函数（TTS/TTI/ASR 缓存、图像与视频处理、SRT 解析、prompt 渲染、Pydantic 模型 YAML 缓存等）。

## 7. 资源与测试

+ `asset/` — 字体文件（kaiti.ttf、jingdianyahei.ttf、fengmingshoushu.ttf、longyinshoushu.ttf、shoujinti.ttf）与 `sound_only.png`。
+ `data/` — ASR 识别结果缓存目录。
+ `doc/` — 已有 `CDA.md`、`ext_ppt.md`；本文档为新增。
+ `examples/` — 示例文件。
