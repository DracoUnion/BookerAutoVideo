# 任务书：为 BookerAutoVideo 新增 `copy` 子命令（视频逆向还原提示词 → Seedance 图生视频复刻）

## 1. 背景与目标

`BookerAutoVideo` 已具备抽帧、图像哈希、多模态 LLM 编排、ffmpeg 封装、YAML 缓存等能力。现需新增子命令 **`copy`**，实现“爆款短视频复刻”工作流：

> **输入一段参考视频 → OpenCV 抽帧 → 感知哈希提取关键帧 → 视觉大模型逆向还原 Seedance 文生图提示词 → Seedance 文生图；同时 SenseVoice 提取文案 → 大模型改写文案；最后 Seedance 根据图片和改写文案生成视频 → ffmpeg 添加字幕/BGM/节奏 → 下载到本地**

要求：**严格遵循现有工程约定**（argparse 子命令注册方式、LLM 公共参数、`openai.py` 客户端层、`util.py` 缓存、`doc/` 文档），**不得破坏任何现有子命令**。

## 3. 功能需求（八阶段流水线）

| 阶段 | 名称 | 输入 | 输出 | 缓存 |
|---|---|---|---|---|
| S1 | 抽帧 | 视频文件 | 按 `sample_fps` 采样的帧序列（内存） | 可选落盘 `frames/` |
| S2 | 关键帧提取 | 帧序列 | 关键帧列表（含时间戳、图片路径、pHash） | `keyframes/` + `keyframes.json` |
| S3 | 逆向文生图提示词 | 关键帧 + 视频时长 | `reversed_image_prompt.txt` | 命中则跳过视觉模型调用 |
| S4 | Seedance 文生图 | 文生图提示词 + 画幅/分辨率 | 图片 URL → 本地图片 | `images/` + `image_task.json` |
| S5 | SenseVoice 提取文案 | 视频音频 | `transcript.txt` | 命中则跳过 ASR |
| S6 | 大模型改写文案 | 原始文案 + 改写要求 | `rewritten_script.txt` | 命中则跳过 LLM 调用 |
| S7 | Seedance 图生视频 | 图片 + 改写文案 + 时长/分辨率/画幅 | 视频 URL | `video_task.json` |
| S8 | ffmpeg 后期 | 视频 + 字幕/BGM/节奏配置 | `<out>/copy_<ts>.mp4` | 已存在则跳过 |

**断点续跑**：任一阶段产物已存在且校验通过，则跳过该阶段；`--force` 强制重跑。

**干跑模式**：`--dry-run` 只执行 S1–S3 与 S5–S6，输出逆向文生图提示词和改写文案后停止，不调用 Seedance 文生图/图生视频，也不执行 ffmpeg 后期。

**路线关系**：画面路线 S1→S2→S3→S4 与文案路线 S5→S6 可并行；当前实现允许串行，但状态字段需独立记录，便于后续并行化。

| `--keep-frames` | flag | 关 | 保留全部采样帧 |

### 4.3 公共参数使用约定

- `-vm/--vmodel`：**视觉模型**（S3 必用）。若未传，回退到 `-m/--model`；二者皆空则报错退出。
- `-m/--model`：文本模型，用于 S6 文案改写；也可用于 S3 提示词最终润色（可选，`--no-polish` 可关）。
- `-k/--key`、`-H/--host`：OpenAI 鉴权与网关，S3/S6 直接复用。
- 重试/温度/超时：沿用入口公共参数。

### 4.4 新增环境变量（`.env` / 系统环境）

```ini
SEEDANCE_API_KEY=
SEEDANCE_BASE_URL=https://ark.cn-beijing.volces.com/api/v3

SEEDANCE_IMAGE_MODEL=seedance-image

SENSEVOICE_BASE_URL=

```

CLI 参数优先级：**CLI > 环境变量 > 默认值**。

## 6. 数据模型（`copy_models.py`）

```python
class VideoMeta(BaseModel):
    path: str
    fps: float
    total_frames: int
    duration: float
    width: int
    height: int

class Keyframe(BaseModel):
    index: int
    time: float
    path: str
    phash: str

class ImagePromptResult(BaseModel):
    reversed_prompt: str
    polished_prompt: str | None = None
    image_ratio: str | None = None
    image_resolution: str | None = None

class ImageResult(BaseModel):
    task_id: str
    image_url: str
    local_path: str

class Transcript(BaseModel):
    text: str
    language: str | None = None
    segments: list[dict] | None = None

class RewriteResult(BaseModel):
    original_text: str
    rewritten_text: str

class SeedanceImageTask(BaseModel):
    task_id: str
    status: str
    image_url: str | None = None

class SeedanceVideoTask(BaseModel):
    task_id: str
    status: str
    video_url: str | None = None

class PostConfig(BaseModel):
    subtitle_path: str | None = None
    bgm_path: str | None = None
    bgm_volume: float = 0.25
    rhythm: dict | None = None

class CopyState(BaseModel):
    video_hash: str
    stage: str                 # done_s1 ... done_s8
    meta: VideoMeta
    keyframes: list[Keyframe] = []
    image_prompt: ImagePromptResult | None = None
    image_result: ImageResult | None = None
    transcript: Transcript | None = None
    rewrite_result: RewriteResult | None = None
    image_task: SeedanceImageTask | None = None
    video_task: SeedanceVideoTask | None = None
    post_config: PostConfig | None = None
    output_path: str | None = None
```

缓存路径：`data/copy/<video_hash>/state.yaml`（复用 `util.py` 的 Pydantic YAML 缓存）。

## 7. 关键实现要点

### 7.1 S1 抽帧
- 优先用 `ffmpeg.py` 封装抽帧到临时目录（按 `sample_fps`）；若封装不便，允许 `cv2.VideoCapture` 逐帧读、按 `step = round(fps/sample_fps)` 采样。
- 必须读取并记录 `VideoMeta`（fps、总帧、时长、宽高）。

### 7.2 S2 pHash 关键帧
- 每帧转 RGB → `imagehash.phash(pil, hash_size)` → 与上一关键帧汉明距离比较，`> threshold` 记为关键帧。
- 首帧必为关键帧；若候选数超 `max_keyframes`，**均匀采样**截断。
- 关键帧写盘：`data/copy/<hash>/keyframes/kf_<i>_t<time:.2f>s.jpg`。
- 边界：无关键帧（如纯色视频）→ 报错退出码 2，提示调低 `--phash-threshold`。

### 7.3 S3 逆向文生图提示词
- 图片压缩：最长边 ≤ 768，JPEG quality 85，base64 内联 `data:image/jpeg;base64,...`。
- 按时间顺序把关键帧写入 user message，附时间点文本。
- **system prompt 固定**（`copy_pmt.py`）：

```
你是一名 AI 绘画提示词逆向工程师。用户按时间顺序提供同一段视频的若干关键帧。
请逆向还原一段可直接用于 Seedance 文生图模型的提示词，要求：
1. 描述主体、服饰、姿态、构图、场景、背景、光线与色调、渲染风格；
2. 给出建议画幅（16:9 / 9:16）与分辨率；
3. 只输出最终提示词，中文为主，必要时保留英文风格关键词，不要任何解释。
```

- 调用 `-vm` 模型；若返回 400 且信息含 `image_url` 不支持，明确报错“视觉模型不支持图片输入”。
- 可选润色：把原始提示词交给 `-m` 模型，输出**一段 final prompt**，用 `--no-polish` 关闭。
- 输出文件：`data/copy/<hash>/reversed_image_prompt.txt`，同时写出到 `<out>/copy_<hash>_<ts>.image_prompt.txt`（dry-run 也产出）。

### 7.4 S4 Seedance 文生图
- 在 `seedance.py` 中新增：
  - `create_image_task(prompt, ratio, resolution, model) -> task_id`
  - `wait_image_task(task_id, timeout, poll_interval) -> image_url`
  - `download_image(url, dest)`
- 鉴权：`Authorization: Bearer $SEEDANCE_API_KEY`，Base URL 来自 `--seedance-host` / `SEEDANCE_BASE_URL`。
- 图片保存到 `data/copy/<hash>/images/seedance_image_<i>.jpg`。
- `state.yaml` 记录 `image_task`，续跑时先查已有 task 状态而非重复创建。

### 7.5 S5 SenseVoice 提取文案
- 从参考视频提取音频：`ffmpeg -i video -vn -acodec pcm_s16le -ar 16000 -ac 1 audio.wav`。
- 新建 `sensevoice.py`，封装：
  - `transcribe(audio_path, language, model, key, host) -> Transcript`
- 支持本地或 API 两种模式：优先环境变量/CLI 指定的 API；若项目已有本地 ASR 封装，则适配到同一接口。
- 输出：`data/copy/<hash>/transcript.txt`，同时写出到 `<out>/copy_<hash>_<ts>.transcript.txt`。
- 无音频或 ASR 失败 → 报错退出码 7，提示检查音频流或 ASR 配置。

### 7.6 S6 大模型改写文案
- 将原始文案、`--rewrite-requirement`（可文件路径或直接文本）、角色设定输入 `-m` 模型。
- 默认改写要求模板放在 `copy_pmt.py`，核心要求：
  - 学习原文案句式、节奏和包袱，不照抄内容；
  - 保留反差结构、情绪共鸣和统一结尾；
  - 每条只讲一件事、一组对比、一个笑点；
  - 像朋友吐槽，不用书面语；
  - 只输出文案，不加标题、分析或建议。
- 输出：`data/copy/<hash>/rewritten_script.txt`，同时写出到 `<out>/copy_<hash>_<ts>.rewritten.txt`。
- `--no-rewrite` 时直接使用 `transcript.text`。

### 7.7 S7 Seedance 图生视频
- 在 `seedance.py` 中新增：
  - `create_video_task(image_path_or_url, prompt, duration, resolution, ratio, model, audio) -> task_id`
  - `wait_video_task(task_id, timeout, poll_interval) -> video_url`
- 图片优先使用 S4 本地图片上传或 URL；文案使用 S6 改写文案；参数来自 `--gen-*`。
- 轮询间隔 3s，超时抛异常，`state.yaml` 记录 `video_task`，续跑时先查已有 task 状态。

### 7.8 S8 ffmpeg 后期
- 新建 `ffmpeg_post.py`，封装：
  - `burn_subtitle(input_video, subtitle_path, output_video)`
  - `mix_bgm(input_video, bgm_path, volume, output_video)`
  - `apply_rhythm(input_video, rhythm_config, output_video)`
- 字幕：`subtitles` 滤镜烧录，或软字幕封装；默认烧录。
- BGM：`amix` + `volume` + 可选 `afade`。
- 节奏：支持 JSON 配置中的 `trim`、`speed`、`concat` 列表；复杂节奏可拆成多步 ffmpeg 调用。
- 无 `--subtitle` / `--bgm` / `--rhythm` 时对应步骤跳过；`--no-post` 整体跳过。
- 后期失败 → 报错退出码 8，保留中间视频路径。

## 8. 错误处理与退出码

| 场景 | 行为 | 退出码 |
|---|---|---|
| 视频不存在/无法打开 | 明确报错 | 2 |
| 未配置视觉模型（`-vm` 与 `-m` 均空） | 报错并提示参数 | 2 |
| 无关键帧 | 报错 + 调参建议 | 2 |
| 视觉模型不支持图片 | 报错 + 换模型建议 | 3 |
| Seedance 文生图/图生视频鉴权失败（401/403） | 报错 + 检查 key/host | 4 |
| 轮询超时 | 报错 + 保留 task_id 供续跑 | 5 |
| 下载失败（重试后） | 报错 + 保留 URL | 6 |
| SenseVoice 无音频/ASR 失败 | 报错 + 检查音频流或 ASR 配置 | 7 |
| ffmpeg 后期失败 | 报错 + 保留中间视频路径 | 8 |
| 任一阶段异常 | 写 `state.yaml` 记录已成功阶段 | 对应码 |

## 11. 验收标准（Checklist）

- [ ] `BookerAutoVideo copy --help` 正常输出，参数齐全，默认值正确。
- [ ] `pyproject.toml` 的三个入口（`BookerAutoVideo`/`bav`/`auto-video`）均可执行 `copy`。

## 12. 约束与注意事项

1. **不改动现有模块的公开行为**：`openai.py`、`util.py`、`ffmpeg.py` 只允许**新增**函数，不允许改签名。
2. **不在 `__main__.py` 里写业务**，只加 `copy_video.reg_subparser(subparsers)` 一行。
3. **提示词与参数解耦**：`copy_pmt.py` 只放模板字符串，便于后续换模型调优。
4. **密钥安全**：日志中不得打印 API Key；`state.yaml` 不落密钥。
5. **大文件处理**：抽帧不得一次性把整段视频读入内存；关键帧 base64 发送前必须缩放。
6. **可测试性**：S2（pHash 选择）、S3 图片编码、S6 文案改写输入组装、S8 ffmpeg 参数组装应拆成纯函数，便于单测；建议在 `examples/` 放一段 5–10s 样片或在测试中生成合成视频（`cv2.VideoWriter` 生成渐变色视频即可覆盖 S1/S2）。
7. **阶段状态独立**：画面路线与文案路线分别记录完成状态，便于并行化和断点续跑。
8. **Seedance 接口适配层**：文生图与图生视频的 SDK/HTTP 差异全部隔离在 `seedance.py`，主流程只依赖抽象方法。
